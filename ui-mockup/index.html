How it works

    
The control plane is a canister.

    
Credits, gating, routing and storage live on-chain. The router picks a plane per request: on-chain for verifiable models, off-chain for frontier speed. Outputs are written to on-chain blob storage and served from the Internet Computer.

  

  

    
  










  
Developer quickstart

    
Point your SDK at the Raven.

    
If it speaks OpenAI, it speaks TRP Router. Change one line. The free tier is open now; TRP credits arrive at token launch.

  

  

    

# one line changes — the rest is the OpenAI SDK you already use
from openai import OpenAI
client = OpenAI(base_url="https://trp-router.icp0.io/v1", api_key="trp_free")

# off-chain image, stored on-chain
img = client.images.generate(model="trp/image-standard", prompt="a raven over gold")

# chat with a model running inside a canister
chat = client.chat.completions.create(
    model="trp/onchain-qwen-0.5b",
    messages=[{"role":"user", "content":"hello from the Internet Computer"}])

Verifiable by design

      
The weights sit in on-chain stable memory. The wasm hash matches onicai's published v0.22.0 release byte for byte. Every completion is produced by the replica — not fetched from a server we ask you to believe in.
